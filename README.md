# SuperToken Website

The static product website for SuperToken, an AI gateway that provides one API entry point for leading text, image, and video models.

## Pages

- `index.html`: Homepage with pricing proof, service advantages, FAQ, verified support contacts, and X / Twitter.
- `models.html`: Model catalog for text, image, and video capabilities.
- `pricing.html`: Separate, comparable pricing views for text, image, and video models.
- `status.html`: Route status page.
- `docs.html`: Documentation landing page.

The site supports Chinese and English, light and dark themes, and responsive layouts.

## Development

```bash
npm install
npm run dev
```

Open `http://localhost:5173/` to preview the site.

## Production Build

```bash
npm run build
```

The deployable static files are generated in `dist/`.

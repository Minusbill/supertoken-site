为什么便宜，还能稳。

折扣取决于分组背后的渠道来源：订阅号池类分组采购成本低，折扣就深；官方直连按原价走，换稳定性。每个分组的来源写在价格目录里。

同一个分组里可以放多个渠道，按优先级排序。主线路返回 429 或超时时，网关在这次请求内改走下一个渠道，客户端看到的仍然是一次正常完成的响应。

需要先注册 OpenAI、Anthropic 或 Google 的账号吗？

不需要分别维护厂商账号。注册 SuperToken、创建 API Key 后，按官网模型广场当前开放范围调用。

Base URL 应该填什么？

Claude Code、CC-Switch 通常使用 https://api.supertoken.cc；Codex、Cursor 和 OpenAI SDK 通常使用 https://api.supertoken.cc/v1。香港节点把域名换成 hk.supertoken.cc。

分组应该怎么选？

Claude 完整体验选 Max，侧重性价比选 Kiro；GPT、Gemini 和图片模型使用各自对应分组。最新分组以官网模型广场为准。

价格会变动吗？

会。最新可用模型与价格以官网模型广场和控制台实际展示为准，使用日志是实际扣费依据。

调用出问题去哪里查？

接入与错误码请查 docs.supertoken.cc；账户、充值和线路问题通过官方帮助中心或客服处理。

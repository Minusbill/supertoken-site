顺序回退 · Failover Groups

主渠道故障，自动切到备用渠道。

同一个分组里可以放多个渠道，按优先级排序。主渠道返回 429 或超时时，网关在这次请求内改走下一个渠道，客户端看到的仍然是一次正常完成的响应。

1

请求进入分组

网关校验鉴权后，命中分组内优先级最高的渠道。

2

主链路优先

正常时始终走延迟最低的主通道，成本与速度兼顾。

3

异常即刻切换

429 / 超时 / 5xx 触发回退，下一个热备渠道顶上。

4

流式无感续传

SSE 长连接保持输出，调用方看到的只是一次正常响应。

FAQ

常见问题

没覆盖到的问题，联系客服或查文档。

需要先注册 OpenAI、Anthropic 或 Google 的账号吗？ + −

不需要。注册 SuperToken 并创建 API Key 后，按官网模型广场当前开放范围调用。

充值余额会不会过期？ + −

不会。余额长期有效，按实际用量扣费，没用完的部分留在账户里。

为什么不同分组的折扣差这么多？ + −

折扣取决于分组背后的渠道来源。订阅号池类分组采购成本低，折扣就深；官方直连按原价走，换稳定性。每个分组的来源写在价格目录里，最终以控制台账单为准。

价格会变动吗？ + −

价格目录定期同步，调整会提前公告。计费以控制台账单为准。

调用出问题去哪里查？ + −

状态页看线路是否正常；接入问题查文档，账户和充值问题找客服。
